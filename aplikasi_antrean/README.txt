APLIKASI ANTREAN KANTIN - VERSI TERPISAH

KONSEP / ALUR:
1. Siswa mengisi nama pemesan.
2. Siswa memilih menu makanan/minuman.
3. Siswa mengisi jumlah dan catatan opsional.
4. Sistem membuat nomor antrean otomatis.
5. Siswa mendapat tiket dan dapat memantau status pesanan.
6. Petugas mengubah status: Menunggu, Diproses, Selesai, atau Dibatalkan.

INSTALASI XAMPP:
1. Ekstrak folder aplikasi_antrean ke C:\xampp\htdocs\
2. Jalankan Apache dan MySQL.
3. Buka http://localhost/phpmyadmin
4. Import file aplikasi_antrean.sql
5. Buka http://localhost/aplikasi_antrean/
6. Halaman petugas: http://localhost/aplikasi_antrean/petugas.php

DATABASE: aplikasi_antrean
KONEKSI DEFAULT XAMPP: user root, password kosong.
Tidak ada login admin dan aplikasi ini terpisah dari aplikasi kasir.
